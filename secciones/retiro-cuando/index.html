Retiro

Una de las metas principales de un plan financiero es el retiro o independencia financiera: acumular suficiente dinero hasta el punto de que genere lo necesario para mantener tu estilo de vida.

Primera pregunta: ¿cuándo me quiero retirar? Esto sirve para saber cuánto tiempo tienes para acumular lo necesario.
